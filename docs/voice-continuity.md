# 语音连贯性 SOP：跨段保持同一角色的声音 ⚠️

> 多段成片里，观众对"换脸"敏感，对"换声"更敏感——脸有角色卡锁，**声音也必须有锚点**。

## 先判断你在哪种模式

| 生成方式 | 声音会继承吗 | 要做什么 |
|---|---|---|
| **视频延长**（接着上一段拍） | ✅ 自动继承音色，无需素材 | 保险起见在提示词加一句：`两位角色的音色、语气延续@视频1中的原声，保持一致。` |
| **独立新生成**（新场景、新一条） | ❌ 不继承 | 必须上传音色锚点素材并绑定（下述四步） |

## 音色锚点四步法

**第 1 步：剪素材。** 从已生成的成片里剪出该角色说话最清楚的一句：

- 长度 **5-10 秒**（官方甜区；上限 30 秒，别贪长）
- **只含这一个角色的声音**——混入其他角色台词或大噪音会把音色带偏
- 优先选**人声最干净的段落**（比如设计过"雨声退远"的台词拍）
- 目标段落是哭戏/情绪戏的话，锚点选**带同类情绪的台词**（带哭腔的句子锁哭腔，比平静台词有效）

**第 2 步：选格式。** MP4 视频片段或提取的音频（mp3/wav）都可以，不用特意转格式。

**第 3 步：上传并绑定。** 视频片段进的是 @视频 槽位，音频进 @音频 槽位：

```
（MP4 片段）
[角色名]的音色参考@视频1中[角色]的声音，仅采用其音色、语气与哭腔，不采用其画面、场景与运镜。

（音频文件）
@音频1 定义[角色名]的音色、语气与哭腔，台词语言为粤语。
```

MP4 绑定必须带"不采用其画面、场景与运镜"的排除——你只要声音，不要让旧场景从素材里漏进新画面。

**第 4 步：语言声明照常写。** 音色锚点不替代语言声明，两者叠加：

```
台词语言：全片台词均为地道粤语（广东话），口型与粤语发音精准匹配。
```

## 台词的 TTS 友好写法

- **短句优先**：口语连读词（如"冚过去"）方言 TTS 容易翻车，改最常用音节的短句（"抱住我做咩啊"）
- **一大一小**：与其一句长吼，不如"大声一句 + 破音一句"——情绪落差更大，TTS 各自更稳
- 台词用 `{ }` 包裹，标注说话人与情绪：`她带着哭腔：{……抱住我做咩啊。}`

## 红线速记

1. 音频/视频参考各自总上限 30 秒；单段 5-10 秒最稳
2. 锚点素材里**只能有目标角色一个人的声音**
3. 哭声、笑声也吃音色——情绪戏的锚点选带情绪的句子
4. 延长段不用锚点也稳；**跨条新生成必挂锚点**，忘了就是换声事故
