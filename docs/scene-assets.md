# 场景资产制作规范

用户确认于 2026-09-11：方案已采用，效果待实测；不是官方强制规格，也不保证生成结果自动一致。

## 必交资产

每个场景交付一张场景主图、一张独立俯视布局图、一张 3×3 场景九宫格。场景资产不含人物，与叙事九宫格分开管理。

| 文件 | 内容与职责 |
| --- | --- |
| scene_master | 场景主图：确定建筑、美术、材质、色彩、时段和光源 |
| scene_layout | 独立俯视布局图：确定门窗、家具、通道、固定物件、机位位置与朝向 |
| scene_grid | 九宫格：按下表展示同一场景的空间视图、关键区域和细节 |

| 格号（从左到右、从上到下） | 内容 |
| --- | --- |
| 1—4 | 四个方向的空间视图，尤其覆盖正反打背景；在布局图标记对应机位与朝向 |
| 5—6 | 两个剧情关键区域，例如入口与谈话桌边；按剧本指定 |
| 7—9 | 三个重要细节，例如窗户、桌面陈设、固定物件；按剧本指定 |

## 制作顺序

1. 剧本确认后，确定场景身份、关键区域及细节清单；没有具体场景时先补齐设定。
2. 制作并审核主图，再确定与它一致的俯视布局。主图看不到的区域需要设计并审核，不能当成模型已经知道的事实。
3. 用主图和布局派生九格。各格保持同一时段、同一布置和物件状态，只改变机位、朝向与取景范围。
4. 审核通过后保留独立机位图；细节不足时补清晰图，再制作叙事九宫格。
5. 每段只挂需要的资产并声明职责。整图参考与拆图参考的优劣留待同条件实测。

## 审核清单

- [ ] 主图、布局图与九格的门窗数量、所在墙面和家具位置一致。
- [ ] 机位可以实际放置，视线、遮挡和通道合理；覆盖所需正反打。
- [ ] 锁定物体在场景内的位置；转向后的画面左右变化不误判为移动。
- [ ] 灯光来源、材质、色彩、时段和道具状态一致。
- [ ] 4＋2＋3 九格完整，不用近似重复图凑数。
- [ ] 无人物、人影、人体倒影及其他人体元素，遵守素材纪律。
- [ ] 场景宫格不推进剧情，与叙事分镜分别命名和绑定。
- [ ] 挂图排除布局标注、宫格边框和编号；仅挂本段需要的参考。
- [ ] 记录实际生成偏差；未经视频实测不标记为已验证有效。

调研依据见 [场景宫格调研](scene-grid-research.md)。
