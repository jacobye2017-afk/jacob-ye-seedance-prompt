# 补镜与修复 SOP（踩坑实录）

> 某一段/某几秒翻车，永远不要整条重跑。修复三条路 + 三个必踩的坑。

## 核心原理：延长是"接着拍"，不是"重拍"

延长只会往视频**末尾追加**内容，不会覆盖已有画面。想重拍结尾：

> **要接哪一帧，就喂哪一段；帧后有旧画面，先剪干净再延长。**

## 三个实测撞过的墙

1. **延长链天花板 60 秒**——成片已到 60s 再点延长（60+N > 60）直接"生成失败"。绕行：剪辑台拼接不受此限，只有平台单条生成链受限
2. **延长源视频单段 ≤30 秒**——喂 51 秒的裁剪版照样失败。补长片结尾时只裁**结尾一小段**（8-15 秒）去延长
3. **提示词描述的"最后一帧"必须真的是素材的最后一帧**——喂错段（比如衔接点在第二段却喂了第一段）会报"prompt和生成模式不匹配"

## 补镜标准流程（替换成片结尾的 N 秒）

1. 剪映：从成片裁出**结尾前的一小段**（8-15 秒，≤30s），裁剪终点 = 你要衔接的那一帧（旧结尾整段剪掉）
2. 即梦：小片段上传 @视频1，走**延长入口**，时长选要补的秒数（4-30s）
3. 提示词：官方延长模板开头 + 新内容时间轴（衔接帧的描述必须与素材最后一帧一致）
4. 剪映：`原成片(裁到衔接帧) + 新产出的追加段` 拼回，接缝两侧是同一帧，无缝

## 三条修复路怎么选

| 情况 | 用哪条 |
|---|---|
| 结尾要重拍 | 上面的补镜流程（裁剪+延长） |
| 中间某几秒要改（换物、删物、改台词语言） | 即梦**智能编辑**：源片先裁到 ≤20 秒，声明 `@视频1为唯一剪辑母版`，一次只改一处，结尾写"除上述修改外全部保持不变"的保留清单 |
| 中间某段整体重演 | 小云雀（xyq.jianying.com）**分段重拍**：时间轴框选坏段只重生成那一段 |

## 延长提示词模板（官方）

```
将@视频1向后延长。延长段第一帧直接衔接@视频1最后一帧（[精确描述那一帧的画面]），
保持人物姿态、空间、光线方向与天气的连续性；每个主体全程保持同一连续个体，
不复制不分裂，人物外观稳定。
[新内容的时间轴分镜……]
```

## 省积分纪律

- 480P 试片，全部满意后才出 720P/1080P 正式版
- 起手多生成：目标 30s → 备 2-3 倍素材量挑选
- 每段首尾预留 0.5-1s 修剪余量（AI 运镜起止最不稳）
