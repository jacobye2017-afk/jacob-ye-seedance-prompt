# 素材纪律：转场/换段时该删哪些图 ⚠️

> **铁律：这段画面里会出现的东西，挂图 + 写绑定职责；不会出现的，一张都别挂。**
> 素材不是越多越稳——每多一份没任务的素材，就多一个乱入风险。

## 为什么必须删

Seedance 2.5 的规矩是"每份素材的职责必须在提示词里声明"。反过来：**挂了却没绑定职责的素材，模型会自己给它找活干**。实测事故类型：

- 挂了男主角色卡但这段他不出场 → 他的脸长到出租车司机头上
- 挂了站台场景图但这段在车厢里 → 站台雨景糊进车窗外
- 挂了上一段的成片视频却没绑定 → 上一段的构图/色调污染新段

## 换段删图检查表（每次新生成前过一遍）

对每一份已挂素材问三个问题：

1. **这段画面里它会出镜吗？** 不会 → 删
2. **它出镜的话，提示词里有没有一行绑定 + 排除声明？** 没有 → 补写或删
3. **它的编号和上传顺序对得上吗？** `@图片N` 跟上传顺序走——顺序一错全部张冠李戴。**优先用平台的 @ 点名内联引用**（直接点素材名），不存在顺序错位问题

## 实战案例：《雨夜》三段的素材增删

| 段落 | 场景 | 挂的素材 | 删掉的素材 | 原因 |
|---|---|---|---|---|
| 第一段（站台） | 雨夜站台 | 女主卡、男主卡、站台图 | — | 三者全部出镜 |
| 第二段（延长） | 站台+出租车驶入 | 女主卡、男主卡、站台图、**出租车外观图**、@视频1 | — | 出租车本段首次出镜，新增并绑定 |
| 第三段（车厢） | 出租车内 | 女主卡、**车厢内饰图**、**音色MP4** | **男主卡、站台图、出租车外观图** | 男主不出场；站台不出镜；镜头禁止切到车外所以外观图也无用 |

第三段如果不删男主卡和站台图，最可能的翻车：司机长出男主的脸、车窗外出现站台。
（表中"音色MP4"的剪法与绑定写法见 [voice-continuity.md](voice-continuity.md)。）

## 绑定声明的标准写法

```
[角色名]对应@图片N，仅采用其外貌、发型与服装，不采用图片背景。
[场景名]对应@图片N，仅参考环境、光线与空间结构，不参考任何人物。
[道具名]对应@图片N，仅定义其外观与材质，不复刻图中的任何文字。
```

排除声明（"不采用……"）和正向声明同等重要——官方明确要求写清"提供什么、不采用什么"，禁止让模型自己猜。

## 道具三级制（V1.5 · 《雨夜》遗伞穿帮的直接立法）

> 对照实验已经做完：《咖啡计划》的手绘雨伞**做了道具卡**——零穿帮；《雨夜》的黑伞**没做道具卡**（只在角色卡里顺带出现+文字描述）——单独出镜的 B-roll 特写立刻翻车（收拢的伞变成撑开翻倒）。

| 级别 | 定义 | 要求 | 例子 |
|---|---|---|---|
| **① 符号道具** | 承担叙事/隐喻，会出特写或 B-roll | **必做道具卡** + 每次出场声明物理状态（军规 #7） | 那把伞、手绘雨伞、定情信物 |
| **② 功能道具** | 被角色使用但不承载符号 | 文字描述到材质+款式+颜色即可 | 咖啡杯、手提包、手机 |
| **③ 背景道具** | 环境陈设 | 交给场景参考图，不单独管理 | 桌椅、绿植、货架 |

2.5 有 30 个图片槽位——一张道具卡的成本几乎为零，一次穿帮重跑的成本是几百积分。符号道具永远做卡。

### 道具卡提示词模板

```
[与视频一致的画幅比]。产品摄影写实风格，[道具名]置于纯色背景中央，
[材质逐项描述]，[颜色]，[新旧与使用痕迹]，[关键辨识特征]。
柔和均匀光，画质细腻。禁止：任何文字、字幕、LOGO、水印、多余物件
```

### 多状态卡（道具有开/合、完好/破损等状态变化时）

每个状态单独出一张卡，绑定时按时间段指定：

```
黑色长柄伞（收拢状态）对应@图片5，（撑开状态）对应@图片6；
25秒前只允许出现@图片5的收拢状态，严禁提前撑开。
```

**卡片锁形，文字锁态**——道具卡锁得住"长什么样"，锁不住"现在是什么状态"；状态必须在每个出场的时间窗里文字重申（军规 #7），两者缺一都会漏。

## 场景参考图本身的纪律

场景图**画面内**严禁出现：人物、路人、人影、人体倒影、手脚、人体局部、海报人物、橱窗模特、人形雕像、模糊人形轮廓。人物永远走独立角色卡。
