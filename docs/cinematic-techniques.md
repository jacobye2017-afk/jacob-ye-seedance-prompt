# 电影感的十一条拍摄手法（速查）

> FORMULA.md 的精简版。每一条都在《雨夜》《以后落雨》两部成片里验证过。
> 一句话概括：**电影感不是"加特效"，是每个镜头都能回答四个问题——光从哪来、镜头为什么在这个位置、这一秒观众该看哪里、这个空镜替谁说话。**

## 画面

### 1. 色彩要签契约，不是调色
给一个颜色分配**叙事身份**，全片守住。
《以后落雨》的契约：**暖橘 = 他**。便利店那盏灯从第一部亮到第三部；机场戏严禁出现任何暖橘（他不在）；她走了半座城，最后停在那盏灯前面。红色只在"逃离"那一拍随出租车入场。
**写法**：色彩弧线写进[全局设定]，每段重申，全局尾部禁止其他偏色。

### 2. 光必须有出处——治 AI 感的头号武器
每束光都要能回答"从哪来"。**面部照度均匀 = 柔光箱脸 = AI 感的最大来源。**
```
光影：唯一光源是窗外流动光带与仪表盘微光；她的脸大部分时间处于暗部，
只有光带扫过时亮起半边脸，随即重新暗下，明暗交替清晰可见；暗部欠曝并保留真实噪点。
禁止均匀提亮面部，禁止美颜式补光。
```
光影分三层写：**光源 → 光行为（怎么作用于雨雾/材质）→ 色调**。

### 3. 焦段是心理语言，不是技术参数

| 焦段 | 观众感受到什么 |
|---|---|
| 24mm | 世界吞没人 |
| 35mm | 纪实之眼、和角色一起在场 |
| 50mm | 人的视线、正常对话 |
| 85mm | 世界只剩这张脸 |
| 100mm 微距 | 物的呼吸（伞、信封、雨刮器） |

**必须写"数值 + 可见效果"**：光写 85mm 是弱信号；`85mm浅景深，背景奶油般虚化，只有面部清晰` 才是方向盘。

## 运动

### 4. 镜头不能站在同一根轴上
同轴特写连续不超过两拍。《雨夜》评审扣分最重的一条就是"15 帧里 7 帧同轴正面哭脸"。
换轴的办法：过肩、侧面、背面、俯视、镜面／水洼／车窗倒影、主观视角。
**最狠的一招**：拍"她看见的"而不是拍她的脸——观众和她一起在人群里找那个不会来的人。

### 5. 呼吸感 = 四件事的和
```
环境微动 + 人物微动 + 镜头微动 + 声音微动
```
"呼吸感"三个字永远不写进提示词，写进去的是它的四个成分：雨丝入光柱、呼出的白气、手持微呼吸、雨声退远。**每拍至少三项。**

## 表演

### 6. 写肌肉，不写形容词——但必须配幅度
"悲伤地看着他"交给运气；"眉头内侧上挑、下巴皱缩颤抖、喉咙吞咽"交给肌肉。
**但只写顺序会浮夸**——模型会把每个线索演到最大。写完必须补：`幅度很小，除此之外面部几乎没有其他动作`。
**线索越少越真，2 个胜过 5 个。**

### 7. 告诉模型"为什么"
每个关键拍在动作后加一句潜台词：
> 情绪分析：他语气平常，但伞柄早已擦干——这份准备暴露了在意。

模型知道动机之后，演得明显更细。这是官方手册的招牌技巧。

## 结构

### 8. 进场要有台阶：建立 → 接近 → 进入
主角不能在第一拍就站在戏剧冲突点上。跨时空的大跳跃交给**桥段 B-roll**。
《以后落雨》的四段桥：雨来（入夜）→ 雨中（雨夜）→ 雨停 → 几年后回来 → 绕路。
**配比铁律**：情绪片 **5 个环境镜头 : 3 个人物镜头**。

### 9. 空镜替角色说话（枕镜头）
不推进剧情，说角色说不出的话：
遗落的伞 = 被放弃的挽留 ｜ 水洼倒影被雨砸碎 = 摇摇欲坠的关系 ｜ 雨刮器 = 心跳 ｜ 空着的围裙挂钩 = 他的位置
选空镜前先问：**它替谁说话？** 答不出就删。

## 声音与真实

### 10. 声音是主观的
- **环境音退远**：她说真心话时雨声退远——观众进入她的耳朵
- **先声后人**：风铃响，一杯热咖啡先从画外伸进来，人后到
- **声音桥**：让哭声跨过剪辑点，两个镜头就焊死了

### 11. 该有人就有人
街道、机场、市井本该有人的地方必须有人，空场就假了。
**而且只写"路人虚化"会得到空城**——必须先正向写数量（"十余名旅客""两三个撑伞的路人"），再写限制。
**空必须是设计出来的**：空站台、空车厢、遗落的伞、空挂钩——那是戏；街上没人不是。
