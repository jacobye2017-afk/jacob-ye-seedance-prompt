# 剪映后期：去 AI 感与导出标准

> AI 感的本质是"太干净"。后期的工作就是有分寸地把画面弄脏。

## 去 AI 感三板斧（剪映）

1. **胶片颗粒**：选中片段 → 调节 → 效果 → **颗粒 20-40**（480P 素材约 25；超过 50 变脏片）。直接盖掉蜡质皮肤感
2. **暗角**：同面板 → **暗角 10-20**
3. **调色**：压暗部、微降饱和、往冷偏一点；**锐化确认为 0**（AI 片最忌锐化）

**三段成片必须统一**：颗粒/暗角对拼好的整条加一次，或三段用同一数值——只处理一段，接缝质感会跳。

## AI 感的提示词级预防（下次生成就写进去）

实测最大的 AI 感来源是**人脸照度均匀得像自带柔光箱**。写法：

```
光影：唯一光源是[环境光源]；人物面部大部分时间处于暗部，
只有[光带/灯光]周期性扫过时亮起半边脸，随即重新暗下，明暗交替清晰可见；
暗部欠曝，光扫过瞬间面部轻微过曝。
画质：高感光胶片颗粒明显，暗部有真实噪点；
湿发结缕成绺，皮肤有真实油光与斑驳泛红。
禁令：禁止均匀提亮面部，禁止美颜式补光，禁止根根分明的干净发丝。
```

配合防AI脸咒语：`保留真实的细腻毛孔与皮肤质感`。

## 导出标准（定稿版）

以下表格保留早期项目的审美预设。**实际项目优先保留已确认的帧率与剪辑时序**：琉璃光院已按 30fps / 900 帧 / 30 秒交付，不为套用 24fps 预设改动已卡准的切点。帧率本身不能保证电影感。BGM 片按 [卡点工作流](workflows/bgm-led-mv.md) 核对音画；表格中的“一键超清”指剪辑软件的一键处理，与后文经过验收的本地超分分开选择。

| 设置 | 推荐 | 原因 |
|---|---|---|
| 分辨率 | 按交付要求选 **1080P** 等 | 导出尺寸不等于原生细节，480P 素材的超分另见下文 |
| 帧率 | **项目已确认的帧率（如 24 / 30fps）** | 保持动作节奏与拍点，帧率本身不决定电影感 |
| AI补帧 | **关** | 补帧=肥皂剧感+快动作涂抹伪影，把去掉的 AI 感请回来 |
| 一键超清 | **关** | 本质是降噪+锐化，会吃掉胶片颗粒、重新磨平皮肤 |
| 码率 | 最高 | 雨夜暗部最吃码率，低码率糊成色块 |
| 格式 | MP4 | — |

## 480P 定稿后的两条交付路径

- **保留已认可镜头与剪辑**：定稿后本地超分再编码。琉璃光院使用 Real-ESRGAN x2plus，先 2 倍超分，再缩放至 1920×1080；保持 30fps、900 帧、30 秒，没有补帧、面部修复或额外锐化。此路线已在本片交付，不代表所有画面都会同样改善。
- **需要原生高分辨率新细节**：可用原提示词与素材重新生成 1080P，但身份、动作、构图可能变化，需要重新验收和剪辑，不能视为已有镜头的无损升级。

选择由画面要求、成本与用户授权决定。普通缩放不等于神经网络超分，超分也不等于原生 1080P；已满意的镜头无需为了分辨率一律重生成。

交付检查：完整解码、实际分辨率、帧率与帧数、时长、音轨有无和同步；检查叶片、脸、眼镜、建筑直线及暗部是否出现新伪影。无声版和配乐版分别命名。
