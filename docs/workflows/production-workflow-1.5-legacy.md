# 制作工作流 1.5（旧流程备份）

状态：历史快照，仅用于和后续流程对照。此处的“1.5”是制作工作流版本名，不改写仓库已有的 2.1 项目版本历史。

基线：结合 Claude Code 新流程之前，沿用本仓库既有的剧本、素材、提示词与修复流程。规则主体见 `AGENTS.md`、`FORMULA.md`、`SKILL.md` 及 `docs/`；本文件是执行顺序的备份，不替代这些详细规范。

## 执行顺序

1. 先把故事写成分拍剧本，列出台词和逐拍情绪变化；用户确认剧本后再写提示词。
2. 按剧本准备角色卡、场景图和道具图。场景图不出现人物；多角度场景使用独立单角度图，不制作场景九宫格。
3. 每段只挂当前镜头所需的参考素材，并在提示词里说明每份素材的用途及不采用的内容；不需要的素材移除。
4. 按 `FORMULA.md` §12 组装视频提示词：参考素材声明、一句话总纲、全局设定、时间轴剧情、全局尾部。
5. 时间轴逐拍写清景别、焦段、一个主要动作、一个运镜、声音、情绪线索和画面内可见的结束状态；处理好连续性、道具状态、物理可行性和电影感军规。
6. 有粤语对白时逐句标语言与语气，控制音节速度；跨段新生成且有对白时准备音色锚点。
7. 交付前逐条执行 `AGENTS.md` 自检。将最终提示词单独保存并以 Python `len()` 实测，硬上限 2000 字符，目标不超过 1900。
8. 用户确认提示词和素材后，在生成页面设置时长与画幅；这些参数不写进提示词。成片翻车时遵循 `docs/repair-sop.md`，一次只修一个目标。

## 1.5 基线的明确边界

- 叙事分镜板用于表达镜头顺序；不把场景多角度图做成场景宫格。
- 不假定参考图或分镜板能让视频模型自动逐格切镜，提示词仍须逐拍写清画面。
- 单次生成、延长、局部编辑、素材数量、提示词长度等平台限制，以项目文档记录及当次页面/接口能力为准。
- 此备份不包含角色照片、生成视频、API 请求/响应、凭证或个人素材；只保存工作方法。
