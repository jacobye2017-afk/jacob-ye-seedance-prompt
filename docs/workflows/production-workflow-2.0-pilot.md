# 制作工作流 2.0（合并制作版）

状态（2026-09-23）：**琉璃光院 MV 已交付；BGM 候选拍点经用户试听确认。** 本流程已进入复用阶段，仍逐项区分验证范围：局部替换、轻微自然风调整、30 秒拼接与本地 1080P 超分已在本片使用；先按 BGM 写新分镜再生成整片的完整闭环待下一条片验证。详细记录见 [琉璃光院复盘](../../examples/rurikoin-mv/review.md) 和 [BGM 试听记录](../../examples/bgm-beat-check/review.md)。这不是官方能力保证，也不代表每种场景、宫格绑定或接续方式都已验证。

版本关系：制作流程 1.5 旧版快照见 [production-workflow-1.5-legacy.md](production-workflow-1.5-legacy.md)。仓库自身的项目版本历史另行维护。

## 阶段 A：剧本先行

以用户指定 BGM 为主的 MV，先执行 [BGM 卡点工作流](bgm-led-mv.md)，得到经过试听的节奏表，再写下面的分拍剧本。对白片继续按剧情节奏推进。

1. 确认故事梗概、片长、语言、调性、对白/音乐要求和投放平台。
2. 按本项目既定方法先交付分拍剧本、对白、逐拍情绪台阶和场景清单，等待用户确认；未确认前不写正式视频提示词。
3. 预估场景、角色、关键道具、镜头数和接续方式，找出多人物、轴线变化、道具交接等风险。

## 阶段 B：锁定场景与调度

4. 每个场景先定美术方向和场景主图，再定独立俯视布局图；布局标出门窗、固定陈设、角色路线、摄影机位置和朝向。主图看不到的空间要单独设计，不能假设模型会补对。
5. 依项目约定制作场景资产九宫格（4 个空间视图、2 个剧情区域、3 个细节）和叙事分镜九宫格。两类九宫格分开制作和命名。
6. 场景资产图保持无人。若需要验证群体站位，可另做独立调度参考图；用无脸剪影或背影表达位置，并只在镜头确实需要时挂入。
7. 宫格首先用于导演审图和规划。视频生成默认挂相关的独立场景视图、角色和道具素材，不把宫格整张自动塞给模型；若要测试整格绑定，单独记录为实验变量。
8. 对话轴线和视线方向逐镜标清。保持 180 度关系；需要换轴时，先用有动机的建立镜头或过渡镜头重新交代空间，不为追求变化而硬跨轴。

## 阶段 C：素材与衔接

9. 角色资产以用户选定并审核的角色参考为身份锚；场景、调度、角色、道具各自分工，避免一张图同时定义相互冲突的信息。角色衣着有剧情变化时独立记录状态。
10. 每个道具记录外观、持有人、位置、朝向和状态变化；提示词写明变化发生在哪一拍。
11. 跨段先画好需要的无脸接续构图：记录上一段末尾状态与下一段开场状态。接续帧和各段并行生成仅作为试拍方案；若依赖实际成片才能确认动作或状态，则必须串行生成，不假定预制帧能自动消除接缝。
12. 选择单次生成或分段时按戏剧段落与连续性决定；遵守当次 Seedance 页面的时长、参考素材和编辑限制，不把 Claude 流程的建议时长当成硬限制。

## 阶段 D：按 Jacob 框架写提示词

13. 每段按 `FORMULA.md` §12 组装：素材职责与排除、一句话总纲、全局设定、逐拍时间轴、场景专属尾部。
14. 保留本项目电影感规则：光源动机、色彩弧线、层次构图、焦段与景别、受控运镜、可观察的表情肌肉线索、潜台词、道具连续性、画框物理可行性和可读的结束状态。
15. 每拍只安排一个核心动作和一个主要运镜，按项目规定设计时间窗；对白依项目语言工程逐句标注。时长与画幅由生成页面设置，不写进视频提示词。
16. 素材逐份声明“采用什么／不采用什么”，不挂无关素材。正向写出需要的人物数量和空间位置，再写避免事项。
17. 最终提示词每段存为独立 TXT，用 Python `len()` 实测；不得超过 2000 字符，目标不超过 1900。提交前走完整项目自检清单。

## 阶段 E：试拍验收与复盘

18. 首次试拍优先选一段场景、少量角色、一个明确的连续动作，并选一个能检验空间/身份/剪辑衔接的关键难点；不要同时改太多变量。
19. 保存提示词版本、使用素材清单、页面参数、任务编号、生成结果和费用信息；不记录或公开 API 密钥、登录凭证。
20. 生成后用 FFmpeg 抽帧联系表检查镜头、身份、构图、色彩、道具和穿帮；对段落接缝查看交界前后数帧。对白片另核对实际声音；无对白片确认音轨符合要求。
21. 每次返修只动一个目标，标明失败位置和修改项。分别记录：本次通过、失败、无法判断、待复测；不能把一次成功推广成普遍规律。
22. 试拍结束后与 1.5 基线对照，按生成成功率、素材一致性、镜头可控性、剪辑接续、返修次数、总耗时和总费用评估。用户确认后再把有效规则升级为正式项目规范。

## 阶段 F：剪辑、超分与交付

23. 将原始生成素材、剪辑版本、BGM、拍点表、交付版分开保存；记录每次替换的源片段和目标时间范围。按实际帧率锁定切点，返修后检查接缝前后数帧。
24. 优先复用已经通过的镜头，单独替换失败片段；构图好的镜头只修需要改变的动态。自然风应体现在枝叶及对应倒影上，建筑与桌面保持稳定。
25. 定稿后按需求选择本地超分或重新生成高分辨率素材。本地超分保留已认可的表演和剪辑，但不等于恢复真实原生细节；见 [后期规范](../post-production.md)。
26. 验证导出时长、帧率、帧数、音轨和完整解码，再做画面与听感验收。跨设备交付使用已授权的可访问链接，并在目标网络验证实际媒体请求；本机文件路径不代表手机可播放。
