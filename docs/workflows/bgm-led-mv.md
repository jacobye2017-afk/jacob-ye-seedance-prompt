# BGM 驱动的唯美 MV：卡点工作流

采用日期：2026-09-23。用户对本次带滴声预览的反馈是“非常好！卡点得很准”。验证的是本段音乐的拍点听感；不是所有音乐自动正确，也不是新片分镜和成片已验收。

## 执行顺序

1. **保存原音轨**：对用户提供的配乐视频先探测音轨，有多条音轨时确认目标。兼容的 AAC 音轨可用 FFmpeg 直接提取而不重编码；若已混有人声和环境音，直接提取会一起保留，不等于音乐分离。
2. **检测候选拍点**：分析正向频谱变化与周期性，输出候选速度、拍点秒数、目标帧位置和强度。标记弱拍、倍速/半速歧义。不能仅凭波形判断乐器、情绪、高潮、乐句或小节第一拍。
3. **做对照试听**：在副本叠加短滴声，保留原 BGM。让用户听是否跟上音乐；未获得试听反馈保持“待确认”。当前工具不能直接听音频时如实说明，用可播放的预览让用户校验。
4. **按确认节奏写分镜**：先选切点，再设计对应的景别、焦段、单一动作、运镜、环境动态和结束状态。每拍切镜不是目标；用有选择的切镜和动作落点保留呼吸感。候选切点由剪辑判断选择，不把任意声学峰值当成情绪转折。
5. **确认剧本与资产**：继续执行项目的剧本确认、无人场景资产、独立角色卡与叙事 3×3 九宫格规则。宫格只负责构图和顺序审核，角色相似度需另查独立资产与生成结果。
6. **生成留余量的素材**：每个生成时间窗遵循本项目 ≥3 秒纪律；在所需成片长度之外预留约 0.5–1 秒首尾裁剪空间，并适配平台当次可选时长。超出单次上限则拆镜；最终切点交给剪辑，不依赖模型每毫秒都服从提示词。
7. **后期按帧剪辑**：锁定项目帧率，按最邻近帧放置切点。整数帧率下 `frame = round(seconds × fps)`；帧从 0 开始。确认动作已经发生且首尾状态可衔接后再裁，不为卡点裁掉核心动作。不默认变速人物表演、补帧或改动 BGM 速度。
8. **分层验收与局部修复**：技术层查完整解码、时长、帧数、音轨与同步；创作层看片听音乐，查节奏、身份、场景、自然动态及接缝。只修失败片段；复用已经认可的镜头。
9. **交付并保存记录**：保存原音轨、分析 JSON、拍点 CSV、对照预览、用户试听结论、分镜与剪辑清单。需要手机预览时使用用户授权的网络渠道并实际验证媒体读取。

## 三种时间不要混用

| 时间 | 用途 | 本次案例 |
|---|---|---|
| 音乐拍点 | 检测到的节奏候选 | 平均间隔约 0.688 秒 |
| 生成时间窗 | 模型完成画面与动作 | 本项目每窗 ≥3 秒，并留裁剪余量 |
| 最终剪辑时长 | 剪辑台上实际保留的长度 | 建议约 3–4 秒一镜；按听感调整 |

“每 3 秒一镜”是之前试片的节奏方案，不是所有 BGM 的硬规则。85mm 人物特写是琉璃光院项目的用户选择；新项目按需求选择，环境 B-roll 可用适合空间与细节的其他焦段。

## 本地工具

依赖：Python、FFmpeg，以及 [requirements.txt](../../tools/bgm/requirements.txt) 中的 NumPy、SciPy、Matplotlib。工具只读取本地输入并写到指定目录，不调用付费生成服务、不上传音轨。

```sh
python -m pip install -r tools/bgm/requirements.txt
ffmpeg -i input.mov -map 0:a:0 -vn -c:a copy bgm.m4a
python tools/bgm/detect_beats.py bgm.m4a --output output/bgm-check --fps 30
```

首轮得到拍点后，由剪辑选择候选切点；本次复现命令如下。**下面的秒数只属于本次 BGM**，新曲不要照抄。

```sh
python tools/bgm/detect_beats.py bgm.m4a --output output/bgm-check-with-cuts --fps 30 --cut-targets 3.45,6.9,11.1,14.6,18.15 --click-until 20.5
```

`--cut-targets` 是剪辑选择的目标秒数，脚本将其吸附到最近候选拍点；它不自动识别乐句。`--click-until` 是人为选定的停止提示音时间，不是自动淡出检测。脚本默认不指定切点、不假设尾声时间，也不覆盖已有结果。

输出为 `beat-map.json`、`beat-markers.csv`、`beat-click-preview.m4a`、`beat-timeline.png`。CSV 支持整数 24/25/30/50/60fps 的非丢帧时间码；29.97 等有理数帧率需另行换算，不套用整数公式。

本次试听与帧位置示例见 [BGM 验证记录](../../examples/bgm-beat-check/review.md)。原曲不随仓库分发，数值样例与脚本可复用。
